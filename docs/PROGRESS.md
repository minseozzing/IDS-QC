## 포트폴리오 구성안

1. 프로젝트 개요 (한 줄 목표, 기간, 개인 프로젝트, 도구)
2. 배경과 시나리오 (가정임을 명시, 참고한 실제 사고)
3. 테스트 대상과 범위
4. 테스트 환경 (구성도 한 장)
5. 요구사항 표
6. 테스트 설계 (정탐·오탐·우회·경계값·대조군과 이유)
7. TC 요약 (요구사항별 Pass/Fail 통계, 전체 목록은 부록)
8. 대표 결함 1~2건 (증거 포함)
9. 수정 및 재테스트 (전후 비교, 회귀 결과)
10. 회고 (환경 이슈에서 배운 것, 한계, 개선점)

핵심은 7~9번. 면접관은 TC 개수보다 "결함을 어떻게 찾고, 증명하고, 고친 걸 어떻게 확인했나"를 본다.
